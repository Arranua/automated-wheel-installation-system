# 01 - Project Overview

## Objective

Design and build a compact automation cell that performs a wheel removal and replacement operation on a small vehicle chassis. The project reflects a discrete manufacturing process using a PLC, sensors, actuators, and staged machine logic.

## Main Functions

- detect vehicle body presence
- home the gantry axes
- remove old wheels from two axle positions
- feed replacement wheels from a magazine
- pick up wheels using a servo gripper
- install replacement wheels onto the vehicle axles
- confirm cycle steps using PLC handshaking

## Why This Project Fits Automation

The machine includes common industrial automation concepts:

- PLC sequencing
- sensor validation
- actuator control
- relay-isolated interfaces
- homing and position referencing
- start/stop/reset behavior
- staged cycle execution
- mechanical and electrical troubleshooting
